# UNITE – Sitio Web Institucional

**Unión para la Integración, la Transformación y la Educación**

## 📌 Descripción

UNITE es una organización no gubernamental ficticia orientada a promover la integración, la educación y el desarrollo integral de las personas mediante iniciativas inclusivas, programas educativos y acciones de transformación social.

Este proyecto consiste en el desarrollo de su sitio web institucional, diseñado para presentar la identidad, misión, visión, valores, principios y áreas de trabajo de la organización.

## 🎯 Objetivo del proyecto

Desarrollar una página web institucional moderna, profesional y adaptable a diferentes dispositivos, que permita dar a conocer la organización y facilitar el acceso a su información institucional.

## 🌐 Secciones del sitio web

- **Inicio:** Presentación de la organización.
- **Quiénes somos:** Misión y visión institucional.
- **Identidad:** Presentación del logotipo y pilares de UNITE.
- **Valores:** Principios y valores institucionales.
- **Áreas de trabajo:** Educación y capacitación, desarrollo comunitario, inclusión social, liderazgo juvenil y promoción de valores.
- **Junta directiva:** Presentación de los integrantes de la organización.
- **Contacto:** Información de ubicación y medios de comunicación.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 🎨 Características

- Diseño adaptable (Responsive Design).
- Navegación intuitiva.
- Identidad visual institucional.
- Menú de navegación interactivo.
- Presentación de información institucional.
- Publicación mediante GitHub Pages.
